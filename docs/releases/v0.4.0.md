# 🚀 DeviceDeck v0.4.0 — delete iPhone photos, WhatsApp from backups, and updates you can see

Delete photos from an iPhone straight from the PC, read and export WhatsApp chats from an iPhone backup, and always see when a new version of DeviceDeck is ready.

### 📱 iPhone and Android
- 🗑️ **Delete photos from an iPhone** — the way Windows' File Explorer does it, through Apple's camera connection, from Photos and from Clean-up (largest photos and videos, duplicates). Always confirmed, with "Copy to this PC first" and a result for each photo. Deleted photos are gone for good, not in Recently Deleted. When the phone doesn't allow it (iCloud Photos, locked, …), DeviceDeck says why and how to do it on the phone.
- 💬 **WhatsApp from an iPhone backup** — WhatsApp and WhatsApp Business chats from any DeviceDeck backup, encrypted ones too: a searchable chat list, each chat with replies, photos, videos, voice notes and documents, and export of one chat or all of them to HTML or PDF with their media, or of all media into a folder per chat.
- 🤖 **WhatsApp media off Android** — copy WhatsApp's photos, videos, voice notes, documents and its own backup files to the PC in one go. The chats themselves are encrypted with a key only the phone has, and DeviceDeck says so.
- ✈️ **Telegram and WhatsApp files on an iPhone** — a guide in App documents: these apps keep their files to themselves, so here's the official way out (Telegram Desktop › Export Telegram data, and the new WhatsApp section).

### 🪟 Windows
- 🔔 **Updates you can see** — an "Update ready" button in the title bar, a "What's new" window with the release notes (in Persian when DeviceDeck is), and a banner inside the app, so you see it even with Windows' Do not disturb on. After an update, "What's new in this version" opens once.
- 📦 **Portable zip too** — the zip now checks GitHub and shows "v… is on GitHub" with a Download button.
- ⚙️ **A fuller Updates card in Settings** — version, channel, when it last checked and what it found, Check now and What's new.

### 🐞 Fixes
- 🔐 Contacts and messages from an encrypted iPhone backup couldn't be opened on a real phone.
- 📜 "Show earlier messages" showed some messages twice.

### ℹ️ Good to know
- Tested on a real iPhone 16 (iOS 27): deleting photos through Windows' camera connection (three test images, gone for good, nothing else touched). WhatsApp reading is tested with a simulated backup only; if a chat looks wrong, please tell us. Every Android feature is still tested against simulated phones only.
- Installed with Setup.exe? This update arrives by itself. The portable zip now tells you when there's a new one.
- Not signed yet, so SmartScreen may warn the first time: More info → Run anyway.

# 🚀 دیوایس‌دک v0.4.0 — حذف عکس آیفون، واتس‌اپ از بکاپ، و آپدیتی که دیده می‌شود

عکس آیفون را مستقیم از کامپیوتر پاک کن، چت‌های واتس‌اپ را از بکاپ آیفون بخوان و خروجی بگیر، و همیشه ببین کِی نسخهٔ تازهٔ دیوایس‌دک آماده است.

### 📱 آیفون و اندروید
- 🗑️ **حذف عکس از آیفون** — همان راهی که File Explorer ویندوز می‌رود، یعنی از اتصال دوربین اپل، از بخش Photos و از Clean-up (بزرگ‌ترین عکس‌ها و ویدیوها، تکراری‌ها). همیشه با تأیید، با گزینهٔ «اول کپی به این کامپیوتر» و نتیجهٔ جدا برای هر عکس. عکس‌های پاک‌شده برای همیشه می‌روند، نه به Recently Deleted. اگر گوشی اجازه ندهد (iCloud Photos، قفل بودن و …)، دیوایس‌دک دلیلش را می‌گوید و راه انجامش روی گوشی را نشان می‌دهد.
- 💬 **واتس‌اپ از بکاپ آیفون** — چت‌های واتس‌اپ و واتس‌اپ بیزینس از هر بکاپ دیوایس‌دک، رمزدارها هم: فهرست چت‌ها با جستجو، هر چت با ریپلای، عکس، ویدیو، ویس و فایل، و خروجی یک چت یا همه به HTML یا PDF همراه رسانه‌هایشان، یا همهٔ رسانه‌ها در یک پوشه برای هر چت.
- 🤖 **رسانه‌های واتس‌اپ از اندروید** — عکس، ویدیو، ویس، فایل‌ها و فایل‌های بکاپ خود واتس‌اپ را یک‌جا به کامپیوتر کپی کن. خود چت‌ها با کلیدی رمز شده‌اند که فقط گوشی دارد، و دیوایس‌دک این را می‌گوید.
- ✈️ **فایل‌های تلگرام و واتس‌اپ روی آیفون** — یک راهنما در فایل‌های برنامه‌ها: این برنامه‌ها فایل‌هایشان را پیش خودشان نگه می‌دارند، پس راه رسمی بیرون آوردنشان این است (در Telegram Desktop گزینهٔ Export Telegram data، و بخش تازهٔ واتس‌اپ).

### 🪟 ویندوز
- 🔔 **آپدیتی که دیده می‌شود** — دکمهٔ «آپدیت آماده است» در نوار بالا، پنجرهٔ «چه چیز تازه است» با متن ریلیز (فارسی وقتی برنامه فارسی است)، و نوار اعلان داخل خود برنامه، تا حتی با روشن بودن Do not disturb ویندوز هم ببینی. بعد از هر آپدیت، «تازه‌های این نسخه» یک بار باز می‌شود.
- 📦 **نسخهٔ zip هم** — نسخهٔ zip حالا GitHub را چک می‌کند و «نسخهٔ … در GitHub هست» را با دکمهٔ دانلود نشان می‌دهد.
- ⚙️ **کارت کامل‌تر آپدیت در تنظیمات** — نسخه، کانال، آخرین بار که چک شد و چه پیدا کرد، Check now و «چه چیز تازه است».

### 🐞 رفع اشکال‌ها
- 🔐 مخاطبین و پیام‌ها از بکاپ رمزدار آیفون روی گوشی واقعی باز نمی‌شدند.
- 📜 «نمایش پیام‌های قبلی» بعضی پیام‌ها را دو بار نشان می‌داد.

### ℹ️ خوب است بدانی
- روی آیفون ۱۶ واقعی (iOS 27) تست شده: حذف عکس از اتصال دوربین ویندوز (سه عکس آزمایشی، برای همیشه پاک شدند و به هیچ چیز دیگری دست نخورد). خواندن واتس‌اپ فقط با بکاپ شبیه‌سازی‌شده تست شده؛ اگر چتی درست نشان داده نشد، خبر بده. همهٔ قابلیت‌های اندروید هنوز فقط با گوشی شبیه‌سازی‌شده تست شده‌اند.
- اگر با Setup.exe نصب کرده‌ای، این آپدیت خودش می‌رسد. نسخهٔ zip هم حالا خبر می‌دهد که نسخهٔ تازه آمده.
- هنوز امضا نشده، پس SmartScreen ممکن است بار اول هشدار بدهد: More info ← Run anyway.
